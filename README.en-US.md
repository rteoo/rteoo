# Hi, I'm Teô!

🇧🇷 Engineer at **[Strateo](https://github.com/strateo)**. I build tools for work I do every day: typing, recording, working with data, and automating the repetitive bits.

Most of my public projects are Windows desktop apps and Python libraries. I like tools that keep data local and make useful things easy to script.

## Desktop apps

- ⌨️ **[SnipType](https://github.com/rteoo/sniptype)** — Expand shortcuts into text, rich content, and forms. A local text expander built in Python for Windows.
- 🎙️ **[SnipVoice](https://github.com/rteoo/snipvoice)** — Dictation with PT-BR/EN-US transcription using local models, plus meeting recording. Built in Python for Windows.
- 📸 **[SnipScreen](https://github.com/rteoo/snipscreen)** — Screenshots, markup, and MP4 screen recording with system and microphone audio. Built in Rust for Windows.

## Python libraries

Small clients for getting official data into scripts and applications.

- 🏦 **[bcb-data](https://github.com/rteoo/bcb-data)** — Economic time series from Banco Central do Brasil's SGS API.
- 📊 **[ibge-data](https://github.com/rteoo/ibge-data)** — Access to IBGE's official APIs.
- 📑 **[cvmbr-data](https://github.com/rteoo/cvmbr-data)** — CVM open data and company filings from RAD/ENET.
- 🌦️ **[inmet-forecast](https://github.com/rteoo/inmet-forecast)** — An unofficial Python client for Brazilian INMET forecasts.

## Other projects

- 🧾 **[strateo/nfse](https://github.com/strateo/nfse)** — A Python client for issuing, querying, and canceling Brazilian service invoices (NFS-e) through the national standard's API.
- 🏠 **[homeassistantpy](https://github.com/rteoo/homeassistantpy)** — A dependency-free Home Assistant client with REST, WebSocket, and explicit JSON tools for agents.
- 📬 **[outlook-pst](https://github.com/rteoo/outlook-pst)** — A Python CLI and plugin for ChatGPT and Claude. Search emails in local files in Classic Outlook.
- 🐂 **[cattle-auction](https://github.com/rteoo/cattle-auction)** — Turn Brazilian cattle-auction videos into structured lot data using transcription, OCR, and LLMs.
- 🧮 **[rpn-calc](https://github.com/rteoo/rpn-calc)** — An RPN calculator built in Python for Windows.
- 🔊 **[rteoo/audio-tray](https://github.com/rteoo/audio-tray)** — A fork of *[tobi/AudioPriorityBar](https://github.com/tobi/AudioPriorityBar)*: a Windows system tray app for managing audio device priorities.
- 🎨 **[design-system-t3code](https://github.com/rteoo/design-system-t3code)** — A design system based on the T3 Code app's default theme. Unaffiliated with T3 Code.
