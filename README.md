# Oi, eu sou o Teô!

🇧🇷 Engenheiro na **Strateo**. Crio ferramentas para o trabalho do dia a dia: digitar, gravar, trabalhar com dados e automatizar tarefas repetitivas.

A maioria dos meus projetos públicos são aplicativos para Windows e bibliotecas Python. Gosto de ferramentas que mantêm os dados locais e facilitam a automação com scripts.

## Apps Desktop

- ⌨️ **[SnipType](https://github.com/rteoo/sniptype)** — Expanda atalhos em texto, conteúdo formatado e formulários. Um expansor de texto local. Feito em Python para Windows.
- 🎙️ **[SnipVoice](https://github.com/rteoo/snipvoice)** — Ditado com transcrição PT-BR/EN-US usando modelos locais e gravação de reuniões. Feito em Python para Windows.
- 📸 **[SnipScreen](https://github.com/rteoo/snipscreen)** — Capturas de tela, anotações e gravação de tela em MP4 com áudio do sistema e do microfone. Feito em Rust para Windows.

Bibliotecas pequenas para levar dados oficiais aos seus scripts e aplicativos.

## Outros projetos

- 🧾 **[strateo/nfse](https://github.com/strateo/nfse)** — Cliente Python para emissão, consulta e cancelamento de NFS-e no Padrão Nacional via API.
- 🏠 **[homeassistantpy](https://github.com/rteoo/homeassistantpy)** — Cliente para Home Assistant sem dependências, com API REST, WebSocket e ferramentas JSON explícitas para agentes.
- 📬 **[outlook-pst](https://github.com/rteoo/outlook-pst)** — CLI em Python e Plugin para ChatGPT e Claude. Pesquise e-mails em arquivos locais no Outlook clássico.
- 🐂 **[cattle-auction](https://github.com/rteoo/cattle-auction)** — Transforme vídeos de leilões de gado brasileiros em dados estruturados de lotes usando transcrição, OCR e LLMs.
- 🧮 **[rpn-calc](https://github.com/rteoo/rpn-calc)** — Uma calculadora RPN. Feito em Python para Windows.
- 🔊 **[rteoo/audio-tray](https://github.com/rteoo/audio-tray)** — Fork from: *[tobi/AudioPriorityBar](https://github.com/tobi/AudioPriorityBar)*, Windows version for system tray app for managing audio device priorities.
- 🎨 **[design-system-t3code](https://github.com/rteoo/design-system-t3code)** — Um design system baseado no tema padrão do aplicativo T3 Code. Sem vínculo com o T3 Code.
