# Oi, eu sou o Teô 👋

🇧🇷 Engenheiro na **Strateo**. Crio ferramentas para o trabalho do dia a dia: digitar, gravar, trabalhar com dados e automatizar tarefas repetitivas.

A maioria dos meus projetos públicos são aplicativos para Windows e bibliotecas Python. Gosto de ferramentas que mantêm os dados locais e facilitam a automação com scripts.

## Comece por aqui

- ⌨️ **[SnipType](https://github.com/rteoo/sniptype)** — Expanda atalhos em texto, conteúdo formatado e formulários. Um expansor de texto local para Windows, com aplicativo na bandeja do sistema e gerenciador visual.
- 🎙️ **[SnipVoice](https://github.com/rteoo/snipvoice)** — Ditado e gravação de reuniões para Windows, com faixas separadas para o microfone e o áudio do sistema.
- 📸 **[SnipScreen](https://github.com/rteoo/snipscreen)** — Capturas de tela, anotações e gravação de tela em MP4 com áudio do sistema e do microfone. Feito em Rust para Windows.

Bibliotecas pequenas para levar dados oficiais aos seus scripts e aplicativos.

## Outros projetos que criei

- 🏠 **[homeassistantpy](https://github.com/rteoo/homeassistantpy)** — Cliente para Home Assistant sem dependências, com REST, WebSocket e ferramentas JSON explícitas para agentes.
- 📬 **[outlook-pst](https://github.com/rteoo/outlook-pst)** — Pesquise e-mails em arquivos PST/OST locais, exporte evidências e visualize alterações antes de aplicá-las no Outlook clássico. Inclui uma CLI em Python e um plugin de skills.
- 🐂 **[cattle-auction](https://github.com/rteoo/cattle-auction)** — Transforme vídeos de leilões de gado brasileiros em dados estruturados de lotes usando transcrição, OCR e LLMs.
- 🧮 **[rpn-calc](https://github.com/rteoo/rpn-calc)** — Uma calculadora RPN.
- 🎨 **[design-system-t3code](https://github.com/rteoo/design-system-t3code)** — Um design system baseado no tema padrão do aplicativo T3 Code. Sem vínculo com o T3 Code.
